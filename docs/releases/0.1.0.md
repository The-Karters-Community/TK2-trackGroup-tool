# TK2 Track Groups 0.1.0

The first standalone Windows release for managing and sharing The Karters 2 track groups. No BepInEx plugin, Python, Node.js or npm installation is required.

## Highlights

- Browse Speedrun and Community collections in Gallery or List view, with named tracks and preview images.
- Four bundled Speedrun groups: Official 16-Track GP SR.com, Seren 24-Track SR.com, CTR99 SR.com and LEGO Racers '99 SR.com — 72 ordered references in total.
- Import/export `.tk2group.json` files or create a group from pasted Workshop IDs and links.
- Rename and reorder your groups directly, using animated drag grips or keyboard-friendly arrows.
- Automatically connect to Steam, check missing subscriptions/content and repair missing tracks. Review named dependencies before confirming downloads or changes.
- Preserve unrelated profile data, compare local and Steam Cloud copies, and retain recovery backups for save changes.
- Check new stable releases at startup and offer verified in-place updates through **Update app**.

## Install

Download `TK2-Track-Groups-0.1.0-win-x64.zip`, extract it into one folder, and run **TK2 Track Groups.exe**. The ZIP has no extra outer folder.

Requires Windows x64, Microsoft Edge WebView2 Runtime, the installed Steam game **0.1.4.18** (app ID **2269950**) and the running Steam client. Keep the game closed while importing or saving; Steam Cloud must be enabled for imports.

The `.zip.sha256` asset provides the archive checksum. The ZIP includes the file manifest used by future updates. The app loads Steam's DLL from your game installation; it does not redistribute game binaries or track assets.

## Verification and limitations

Automated checks cover save preservation, catalog checksums, editing, unresolved dependencies, download failures and updater validation. Real-account imports and playable Workshop tracks have been verified in the game. Missing-item download failure/progress paths include controlled tests; a fresh missing-item network download has not been independently verified in the release test account. Private or deleted Workshop items cannot be restored. Stop and resolve any local/Steam save conflict shown by the app.
