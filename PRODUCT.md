# TK2 Garage

## Register
Product: a desktop and browser companion for The Karters 2 players.

## Users and purpose
Players organize official and Workshop track groups, manage customization presets, and share portable group files. Desktop users connect to Steam. Browser users explicitly grant access to their own local files; no player data is uploaded.

## Experience
The user requested visual choices modeled on the game: character, skin and variant grids, dedicated vehicle/wheel/sticker tabs, direct group membership management, smooth reordering, and actions that remain visible. Preserve the existing restrained dark olive palette and lime selection accent. Familiar game imagery should carry recognition. Avoid technical IDs as item names, long dropdowns, hidden actions, misleading previews, and unnecessary confirmation pages.

## Accessibility and safety
Keep keyboard navigation, native dialog focus trapping, accessible button names, reduced motion, and usable layouts at small window sizes. Preserve unrelated save fields and block conflicting writes. Mod content remains on the owner’s machine.
